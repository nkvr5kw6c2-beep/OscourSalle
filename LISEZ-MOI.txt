IRON LOG V2 — Mise à jour iPhone
================================

Contenu :
- index.html : application, bibliothèque d'exercices illustrée, analyse locale, historique et suppression de séances.
- manifeste.json : configuration de l'application iPhone.
- sw.js : cache hors ligne, version renouvelée.

INSTALLATION SUR GITHUB (iPhone)
1. Dans le dépôt OscourSalle, choisis la branche utilisée par GitHub Pages (la capture précédente montrait « Principal »).
2. Ouvre chaque ancien fichier puis utilise le crayon Modifier pour remplacer tout son contenu, ou envoie les fichiers de même nom par Upload files si GitHub propose bien le remplacement.
3. Remplace index.html, manifeste.json et sw.js par ceux de cette archive. Ne téléverse pas l'archive ZIP elle-même.
4. Valide avec « Commettre les changements » sur la branche principale.
5. Attends quelques minutes, puis ouvre l'URL GitHub Pages et actualise.
6. Si l'ancienne version persiste, ferme/réouvre Safari. Le service worker a une nouvelle version de cache.

DONNÉES
Les performances V2 utilisent une nouvelle clé de stockage local. Les données de l'ancienne version peuvent ne pas apparaître automatiquement. Exporte les anciennes données avant mise à jour si elles comptent pour toi. Les données restent locales au navigateur de l'appareil et ne se synchronisent pas.

IMAGES
La bibliothèque contient des illustrations schématiques intégrées au code (pas des photos de salle). Les explications donnent les muscles ciblés, la mise en place et un conseil technique pour chaque exercice.


CORRECTION DES VISUELS — VERSION 3
- Les cartes utilisent désormais 22 visuels réalistes locaux (dossier images/), au lieu des dessins schématiques.
- Les images sont intégrées au dépôt : pas de clé API ni de service externe requis.
- Le service worker est passé en v3 et met en cache les images pour l'usage hors ligne.
- Pour publier, envoyer/remplacer index.html et sw.js ET ajouter le dossier images/ complet (22 fichiers JPG).

INSTALLATION SIMPLE SUR IPHONE : les 22 visuels sont intégrés directement dans index.html. Il suffit de remplacer index.html et sw.js sur GitHub; manifeste.json et LISEZ-MOI.txt peuvent rester tels quels.

VERSION 4 — AJOUTS
- Chronomètre de repos de 90 secondes, lançable depuis chaque série; pause et réinitialisation.
- Nouvelle catégorie Alimentation : repère protéique indicatif selon le poids, exemples de repas et habitudes simples.
- Stockage local conservé; aucune API externe ni clé secrète.
- Pour publier, remplacer index.html et sw.js sur GitHub Pages.
