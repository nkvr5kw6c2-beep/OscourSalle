IRON LOG — Suivi Musculation iPhone
====================================

Fichiers à publier à la racine du dépôt GitHub :
- index.html
- manifest.json
- sw.js
- LISEZ-MOI.txt

IMPORTANT
- Le suivi enregistre les performances dans le stockage local du navigateur de cet appareil.
- Exporte régulièrement une sauvegarde depuis l'onglet Données & réglages.
- Le bilan du coach est une analyse automatique locale fondée sur des règles; il ne s'agit pas d'un modèle d'IA générative.
- Aucune clé API ni aucun service externe n'est utilisé.
- Pour ajouter une véritable IA générative plus tard, il faudra un backend sécurisé qui garde la clé API côté serveur, jamais dans le dépôt ou le navigateur.

Publication GitHub Pages depuis iPhone
1. Ouvre le dépôt GitHub et va dans Code.
2. Supprime ou remplace les anciens fichiers index.html, manifeste.json, sw.js et manifest.json si nécessaire.
3. Ajoute les fichiers de cette archive à la racine (Upload files), puis valide avec Commit changes.
4. Dans Settings > Pages, choisis Deploy from a branch, la branche contenant les fichiers (souvent main) et /(root).
5. Attends la fin du déploiement.
6. Ouvre l'URL GitHub Pages dans Safari. Actualise la page; si l'ancienne version persiste, ferme puis rouvre Safari ou efface les données du site uniquement après avoir exporté les performances.
7. Pour l'icône iPhone : Safari > Partager > Sur l'écran d'accueil > Ajouter.

Les performances sont locales à ce navigateur et ne sont pas automatiquement transférées quand on remplace le code ou change d'appareil. Les mises à jour du site ne devraient pas effacer le stockage local, mais garde des sauvegardes JSON régulières.
