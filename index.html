Comment ça fonctionne ?

Cette version réalise une analyse automatique locale (règles de progression, régularité, séries et charges). Ce n'est pas encore un modèle d'IA générative : aucune donnée n'est envoyée à un serveur. Les conseils sont des repères, pas un diagnostic ni une obligation d'augmenter la charge.

Confidentialité

Les performances sont conservées dans le stockage local du navigateur sur cet appareil. Elles ne se synchronisent pas automatiquement avec un autre appareil. Effacer les données du navigateur peut les supprimer.
